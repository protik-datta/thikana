# Thikana Estates

Frontend-only real estate marketplace (React, Vite, Tailwind CSS 4, Framer Motion).

    npm install
    npm run dev
    npm run build

Brand name, contact details and announcement text live in `src/constants/brand.js`.
Navigation lives in `src/constants/navigation.js`. Routes live in `src/routes/routeConfig.js`.
Design tokens (colour, type scale, radius, shadow) live in `src/index.css`. Motion presets live in `src/lib/motion.js`.
